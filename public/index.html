    Sign-in

    Try the sign-in Functions. The passcode is needed only if BOARD_PASSCODE is set.

    What is enabled

    • Netlify Functions: /api/health runs the checks above on every load.
    • Netlify Database (Postgres): the full table set from the specification (users, sessions, snippets, cards, categories, labels, cell notes, notes, comments, locks, relations, evidence, propositions, events), applied by Netlify's automatic migrations.
    • Append-only audit log: triggers reject UPDATE, DELETE and TRUNCATE on events; npm test proves it against a throwaway database.
    • Netlify Blobs: the snapshots store accepts, returns and deletes CSV files.
    • Scheduled function: scheduled-snapshot runs every 15 minutes and records a heartbeat.
    • Sign-in and sessions: /api/sign-in, /api/sign-out and /api/session. Access IDs are stored only as scrypt hashes; sessions last 12 hours in an HTTP-only cookie; five failed attempts lock a client out for 15 minutes. Functions that touch board data wrap their handler in withSession.
    • Privacy headers: every path sends X-Robots-Tag: noindex, and robots.txt disallows all crawlers.

    Not built yet

    • Board API: import, move, copy, pile edit, note, comment, relation, events-since, snapshot, export
